# 🌸 任务花园 (Task Garden)

> 打卡成功，花开满枝；拖延失败，入土为安

一个将任务管理与花园养成结合的网页应用。完成任务可以在草地上种植花朵和树木，拖延则留下棺材和墓碑——你的每一次选择都在改变这片土地。

## ✨ 功能

- 📋 **任务管理** — 短期/长期任务，累计打卡，延期机制
- 🌸 **花园系统** — 完成任务获得花，全勤获得树，失败留下棺材/墓碑
- 🎨 **Canvas 渲染** — 蓝天白云的草地场景，支持拖拽平移、滚轮缩放
- 🌿 **真实植物物种** — 7种花卉（蔷薇、向日葵、薰衣草、樱花、雏菊、郁金香、蓝铃花）+ 5种树木（橡树、松树、枫树、柳树、榕树）[持续扩充ing]
- 🏆 **成就系统** — 连续打卡里程碑、动物访客、徽章收集
- 🎉 **鼓励机制** — 打卡成功弹出鼓励语 + 五彩纸屑庆祝
- 💾 **本地存储** — 所有数据保存在浏览器 localStorage，无需注册

## 🚀 使用方式

直接打开 `index.html` 即可使用，无需安装任何依赖。

或访问 GitHub Pages: **[han03620.github.io/task-garden](https://han03620.github.io/task-garden/)**

## 🎮 操作指南

| 操作 | 方式 |
|------|------|
| 新建任务 | 点击「＋ 新建任务」或按 `Ctrl+N` |
| 打卡 | 在任务卡上点击「✅ 打卡」 |
| 超时延期 | 超时打卡时自动弹出延期面板（仅一次） |
| 放置物品 | 完成任务后点击「去荒野布置」，在草地上点击放置 |
| 荒野导航 | 🖱️ 拖拽平移 \| 滚轮缩放 |
| 取消操作 | 按 `Esc` |

## 📦 技术

- 纯 HTML/CSS/JS，单文件应用
- Canvas 2D 渲染
- localStorage 持久化
- 零依赖，零构建
